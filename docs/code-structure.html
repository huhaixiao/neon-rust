Neon Rust 代码结构

Godot 4.7.2 · 2D 俯视角双摇杆 · 1600×1000 场地
3 个 autoload 6 个场景 11 个 .gd / 1,388 行 资源全部脚本生成 零外部依赖

1 · 场景树：一个 Main 挂 10 个子节点，3 组职责

2 · 三层协作：autoload 存全局，场景树存实体，信号连两边

3 · 11 个脚本各管什么

脚本 行 职责
game_state.gd95全局状态 + 7 个信号 + 最高分存档
input_setup.gd48运行时注册 InputMap（键鼠 + 手柄并存）
fx.gd156粒子 / 闪光 / 残影 / 音效池
player.gd237双摇杆移动、右摇杆优先、三连发、冲刺无敌帧、超载
enemy.gd203三种敌人 AI + 受击闪白 + 死亡掉落
bullet.gd73敌我共用弹体，setup() 决定阵营与碰撞层
pickup.gd64漂浮掉落物：血包 / 超载
spawner.gd145波次预算、边缘涌入、清波奖励、难度 ramp
camera_rig.gd36跟随 + 衰减式 trauma 震屏
hud.gd202HULL/WAVE/SCORE、暂停与死亡界面、设备感知文案、调试浮层
main.gd129关卡装配、暂停/重开/全屏、手柄事件日志、暂停冻结
合计1,388玩法集中在 player / enemy，表现集中在 fx / hud

4 · 目录分工

scenes/ · 6 个
main.tscn 是唯一主场景，其余 player / enemy / bullet / pickup / hud 都是可复用预制体。
scripts/ · 11 个
一个脚本一类职责，没有跨脚本直接调用对方私有方法，全部经 Game 或信号。
assets/ · 13 png + 8 wav
全部由 tools/generate_assets.py 与 generate_sounds.py 用标准库生成，可随时重烘焙。
tests/ · 3 个
smoke_test 验开局与射击，pause_test 验暂停后位移为 0，capture 出验收截图。
tools/ · 导出与生成
package_deck.sh / package_deck_debug.sh 出 zip，install-on-deck.sh 装 .desktop。
docs/ · 说明
screenshots/ 是验收图；本页是从 main.tscn 与脚本头注释生成的代码结构。

5 · 要改代码，从这三处进

手感/数值 → scripts/player.gd 顶部的 @export：move_speed 430、dash_speed 1500、fire_interval 0.085、bullet_damage 18。
敌人/波次 → scripts/enemy.gd 的三种类型分支，配合 scripts/spawner.gd 的波次预算与 hp_ramp。
键位/文案 → scripts/input_setup.gd 注册 action，scripts/hud.gd::_refresh_input_copy() 决定手柄态还是键鼠态文案。
数据来源：neon-rust 仓库 scenes/main.tscn、scripts/*.gd（HEAD 37a0c1b）。图中数值为当前 @export 默认值。
