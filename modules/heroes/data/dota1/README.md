# DotA 1 数值参考（只做数值，不做素材）

这里存的是 DotA 1（War3 地图）的**纯数值表**，作为本项目英雄/兵线/建筑的平衡基准。
没有任何 War3 / DotA 的模型、贴图、音效、技能图标——那些既不能随仓库分发，2D 管线也吃不下。
本项目的英雄用自绘 + 致敬原型（如 `小黑 / 寒霜射手`），数值可以有出处，名字和美术不搬。

## 文件

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `heroes.json` | 6 个原型英雄：小黑、冰女、剑圣、巫医、骷髅王、火女 | 17173 DotA1 英雄页、iCCup、豆丁 6.48 属性大表 |
| `creeps.json` | 近战兵 / 远程兵 / 投石车 / 高级兵 / 超级兵 / 旗手 | DotAWiki 6.83d、17173 兵种图鉴 |
| `structures.json` | 一~四塔、近战/远程兵营、世界之树 | 52PK 塔解析、D1Stats 7.00 changelog（改动前的 6.x 值） |
| `mechanics.json` | 波次节奏、升级周期、经济、护甲公式 | DotAWiki 6.83d、iCCup 知识库 |

每条数据都带 `sources`，不同来源版本不一致的地方按条目各自标注——不要把它们当成同一版本的连续表。

## 版本口径

DotA 1 的数值在 6.48 → 6.83 之间改过不少。目前混用了三档：

- **6.48**：豆丁那张属性大表（冰女、剑圣、火女取自这里）。
- **6.7x（6.68~6.72）**：17173 英雄页（小黑、骷髅王）。
- **6.83d**：DotAWiki 的兵线表（小兵数值最完整）。

做平衡时建议**统一以一档为准**，混档只在「只关心相对强弱」时可用。

## 和本项目字段的对应

`HeroDef`（`modules/heroes/data/hero_def.gd`）已有的字段：

| Dota1 字段 | HeroDef 字段 | 说明 |
| --- | --- | --- |
| `damage_min/max` | `damage` | 我们只用一个值，取 `(min+max)/2` 再按缩放系数换算 |
| `attack_interval` | `attack_interval` | 直接用，我们不做敏捷攻速加成 |
| `attack_range` | `attack_range` | 直接用（Dota1 与像素接近 1:1） |
| `move_speed` | `move_speed` | 直接用 |
| `health` | `health` | 直接用 |
| `projectile_speed` | `bullet_speed` | 直接用 |
| `armor` | 暂无 | 现在敌人没有护甲机制，可留到有护甲时再接 |
| `signature.frost_arrows.slow_pct` | `slow_factor` | 取 4 级值或按等级曲线 |

**缩放提醒**：现在 `HeroCatalog.DROW` 是伤害 26 / 间隔 0.58s，而 Dota1 原值是 44-55 / 1.7s。
我们的小兵血量也比 Dota1 低一个量级，所以不要直接把 Dota1 伤害塞进去，否则一枪一个小兵。
建议固定一个 `dota1_scale` 系数（先按 0.5 左右试），所有英雄同乘，保证相对强弱不变。
